# Data Attribution

## Source

This project uses company-wise LeetCode interview question data vendored from the following public repository:

**Repository:** [leetcode-companywise-interview-questions](https://github.com/snehasishroy/leetcode-companywise-interview-questions)  
**Author:** [snehasishroy](https://github.com/snehasishroy)  
**Commit:** `e095c259cfd036e3ddb6886e84d7075c2faac477`  
**Snapshot Date:** 2026-08-16

## What Was Copied

Only the CSV files (`thirty-days.csv`, `three-months.csv`, `six-months.csv`, `more-than-six-months.csv`, `all.csv`) from company subdirectories were copied. No README files, source code, workflows, images, or hidden directories were included.

**Files copied:** 1642 CSV files across 659 company directories.
